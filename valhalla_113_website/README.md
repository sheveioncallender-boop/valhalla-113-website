# Valhalla 113 Website

Odoo website landing page module for Valhalla 113 Grill & Bar.

## Install on Cloudpepper

1. Upload or push the `valhalla_113_website` folder into your Odoo addons repository.
2. Restart/rebuild the Odoo service from Cloudpepper.
3. In Odoo, activate Developer Mode.
4. Go to Apps, click Update Apps List, then search `Valhalla 113 Website`.
5. Install the module.
6. Visit your website homepage or `/valhalla-113`.

The module attempts to replace the default homepage content and also creates a standalone page at `/valhalla-113` as a fallback.
