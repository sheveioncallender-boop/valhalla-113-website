# Valhalla 113 Website

Odoo website module for Valhalla 113 Grill & Bar.

## Install
1. Drag the `valhalla_113_website` folder into your Odoo addons GitHub repo.
2. Push to GitHub and rebuild/restart in Cloudpepper.
3. In Odoo, activate Developer Mode.
4. Go to Apps > Update Apps List.
5. Install `Valhalla 113 Website`.
6. View the page at `/valhalla-113`.

## Notes
This safe build does not automatically override the default Odoo homepage. This avoids install issues from homepage inherit/xpath conflicts. After confirming the page works, you can add it to the website menu or set it as the homepage from Website > Site > Pages.


Odoo 18 compatible version. View page at /valhalla-113.
